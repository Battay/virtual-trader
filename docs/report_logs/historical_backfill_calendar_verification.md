## Methodology

The current saved state was used to select the live unresolved population, excluding the now-successful 2024-11-22 date. Fields from the earlier gap audit were preserved, including attempts, response sizes, raw evidence, and its recommendation. Evidence was checked in the requested order: official PSX calendars/notices, official government evidence, reliable historical calendar/reporting, then local surrounding successful CSV dates and empty official historical-table responses.

An empty 903-byte table was never treated as holiday proof. `CONFIRMED_NON_TRADING` requires an official PSX calendar/notice or a contemporaneous source explicitly reporting a PSX closure. `LIKELY_NON_TRADING` uses public-holiday evidence plus the local surrounding-session pattern where no sufficiently strong date-specific PSX notice was located. `LIKELY_TRADING_GAP` is used where the official calendar excludes the date and affirmative activity/finality evidence makes the gap suspicious. No date was classified from holiday proximity alone.

Web verification was available. Each CSV record contains its evidence URL. Some older records remain deliberately “likely” because the search did not locate a date-specific official PSX notice, even when the public-holiday pattern is strong.
